Static Website on S3
Using GitHub Actions

Host your static website on Amazon S3 and automate deployments using GitHub Actions. Push your code to GitHub and let your CI/CD pipeline handle the deployment.

Explore the Steps ↓

How It Works

From writing code to deploying your website automatically

📦

01. Create S3 Bucket

Create an Amazon S3 bucket to store your website files.

🔐

02. Configure IAM

Create a role and least-privilege policy for GitHub Actions using OIDC.

🐙

03. Push to GitHub

Store your HTML code and workflow in a GitHub repository.

⚙️

04. Automate Deploy

GitHub Actions validates and uploads your website to S3.

Technologies Used

🐙 GitHub: Source code management

⚙️ GitHub Actions: CI/CD automation

☁️ Amazon S3: Static website file storage and hosting

🔐 AWS IAM: Access control and permissions

📄 HTML + Inline CSS: Website design

🚀 Final Result

A static website deployed to Amazon S3 automatically whenever you push changes to the main branch of your GitHub repository.
